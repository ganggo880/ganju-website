## 1. 系統架構與部署概要 (Architecture Overview)

本系統為專為「港居不動產開發有限公司」（統編：`96797997`，特許租賃住宅管理證號：`(112)登字第013739號`）量身打造之高階現代化品牌官方網站與 13 大不動產專業線上工具集。

### 1.1 架構核心亮點
1. **純靜態無伺服器 (Zero-Backend Serverless)**：發布於 GitHub Pages 高速全球 CDN，零伺服器維護成本、零資料庫被入侵風險、抗 DDoS 攻擊。
2. **純本地零知識運算 (Zero-Knowledge Privacy)**：所有線上工具（轉檔、OCR 辨識、EXIF 水印、合約產生、修繕瑕疵存證）皆在使用者瀏覽器本地端以 Canvas/Blob/WebAssembly 運算完成，敏感證件與合約**絕對不上傳任何雲端**，符合台灣《個人資料保護法》最高合規標準。
3. **PWA 漸進式 Web 應用支援 (100% 離線可用)**：系統內建 Service Worker (`sw.js`)，同仁於手機或平板即使在地下室、無收訊案場，全站 15 頁與所有線上工具皆可 100% 離線秒開。
4. **MarTech 全域轉換追蹤**：內建 `js/tracking.js`，雙向映射 GTM、GA4 與 Meta Pixel，自動捕捉 LINE 預約與電話撥打。

## 2. 房源管理與資料契約維護指引 (Listing Management)

首頁房源區之物件資料來源為根目錄之 [`data/listings.json`](file:///home/ken-ubuntu/gdrive_folder/ai agent/Matt Pocock skills/data/listings.json)。

> [!IMPORTANT]
> **維護重要規範**：
> 1. 本檔案在生產環境中由「出租物件自動刊登」系統（`listing_auto`）透過 GitHub API 自動排程更新同步。
> 2. 如需人工緊急調整房源，請務必遵循以下 JSON 欄位契約，以免導致前端解析異常。

### 2.1 房源 JSON 資料欄位契約

| 欄位名稱 | 型別 | 必填 | 說明與範例 |
|---|---|---|---|
| `id` | String | 是 | 唯一房源識別代碼（例：`"kh-001"`、`"zp-2024"`） |
| `title` | String | 是 | 房源標題（例：`"小港宏平特區 典雅三房平車高樓景觀宅"`） |
| `type` | String | 是 | 方案類型（`"包租"` 或 `"代管"`） |
| `status` | String | 否 | 物件狀態：`"available"`（招租中）或 `"rented"`（**已圓滿出租**） |
| `is_rented` | Boolean | 否 | 布林值已出租標記（`true` 或 `false`） |
| `area` | String | 是 | 行政區與生活圈（例：`"小港區・宏平生活圈"`） |
| `layout` | String | 是 | 格局描述（例：`"3 房 2 廳 2 衛 1 平車"`） |
| `size` | String | 是 | 登記權狀建坪或室內實坪（例：`"42.5 坪"`） |
| `price` | Number | 是 | 月租金金額（新台幣元，例：`28000`） |
| `features` | Array | 是 | 特點標籤陣列（例：`["高樓採光", "台電計費", "外商首選", "附家具家電"]`） |
| `image` | String | 是 | 封面實景照路徑（例：`"assets/kh-001.jpg"`） |
| `vr_url` | String | 否 | 360° VR 全景導覽網址（支援 Matterport、720度或 3D 營運島 iframe） |
| `description`| String | 否 | 房源詳情與生活機能介紹 |

### 2.2 房源已出租處理 SOP（RFP §5.3 SEO 留存標準）

當房源成功簽約出租時，**嚴禁直接刪除該房源或下線頁面**（直接刪除會造成 Google 搜尋收錄與社群分享連結變成 404 死連結，嚴重損害網站權重）：
1. **標記狀態**：將該筆資料之 `"status"` 改為 `"rented"`（或 `"is_rented": true`）。
2. **前端自動反應**：
   - 卡片自動套用優雅半透明遮罩與灰階防呆效果。
   - 卡片左上方自動懸掛深藍色「已圓滿出租」角標。
   - 房源詳情彈窗自動頂部置入「【此房源已圓滿出租成交】本頁面保留供行情與格局參考」公告橫幅。
   - 預約諮詢按鈕自動轉換為「加 LINE 諮詢同社區相似房源」，點擊後 LINE 帶入預約訊息：「您好，我看到【房源名稱】已圓滿出租，想諮詢同社區或周邊是否有相似優質房源釋出？」，將死流量轉化為源源不絕的新名單。

### 2.3 360° VR 虛擬實境看房設定

若房源有委託拍攝 360° VR 環景或 Matterport：
1. 取得 VR 分享網址（如 `https://my.matterport.com/show/?m=...`）。
2. 於該筆房源 JSON 中填入 `"vr_url": "https://..."`。
3. 前端房源卡右上角將自動點亮金色「360° VR」標章，彈窗內自動載入自適應 16:9 VR 漫遊視窗。

## 3. 租務專欄文章發布與維護指南 (Blog Management)

首頁之租務專欄 (`#blog`) 提供房東包租代管知識庫、最新法規與稅務優惠解析，是吸引自然搜尋流量（SEO Organic Traffic）的重要樞紐。

### 3.1 文章結構與彈窗文章格式

專欄文章採用現代化無跳轉深度閱讀彈窗（`#articleModal`），讓讀者在不離開官網首頁的情況下完整閱讀精美長文：
- 文章卡片位於 `index.html` 的 `.blog-grid` 內。
- 點擊卡片將透過 `openArticle(articleId)` 呼叫對應之文章資料物件。
- 文章物件具備：`title`、`date`、`readTime`、`badge`、`cover`、`content`（支援語意化 HTML 段落、重點引用塊、法令對照表與文末工具 CTA）。

### 3.2 發布新文章必備檢核清單
- [ ] **法規引用正確**：確認租金免稅額已更新為法定最新標準（每屋每月 **15,000 元**）、必要費用率為 **60%**（《租賃住宅市場發展及管理條例》第 17 條）。
- [ ] **SEO 結構化資料同步**：於 `index.html` 檔尾之 `BlogPosting` JSON-LD 中新增該篇文章之 schema 標記（含 `headline`、`datePublished`、`articleBody`、`image`、`author`）。
- [ ] **Sitemap 更新**：若專欄有獨立靜態頁面擴充，同步於 `sitemap.xml` 中更新網址與 `<lastmod>`。

## 5. PWA 與 Service Worker 更新發布標準作業程序 (PWA SOP)

當官網檔案（HTML、CSS、JS 或圖片）進行重大更新發布時，為確保全球使用者與同仁手機能正確載入最新版本：
1. **開啟 `sw.js`**：
2. **遞增版本號**：
   ```javascript
   const CACHE_NAME = 'ganju-pwa-v1.7'; // 每次重大更新版本號 +0.1
   ```
3. **檢查預載清單**：確認 `PRECACHE_ASSETS` 陣列包含所有最新新增之頁面與資源。
4. **Git 提交與推送**：推送到 GitHub main 分支後，瀏覽器檢測到 Service Worker 檔案字節變動，將自動在背景快取新版並於下一次開啟時平滑無縫更新。
