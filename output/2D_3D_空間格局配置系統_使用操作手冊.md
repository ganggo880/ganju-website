## 壹、系統簡介與環境需求

### 1.1 系統開發初衷
在包租代管與老屋活化業務中，業務同仁常需在現場勘查後迅速向屋主提出「隔間優化與收益提升方案」。以往需依賴專業建築師或設計師使用複雜且高門檻的 AutoCAD / 3ds Max 軟體，出圖耗時且溝通成本高。

本系統專為**港居不動產內部同仁**量身打造，將繁瑣的 CAD 繪圖與 3D 建模完全轉化為**免指令、純滑鼠拖曳、參數化連動**的直覺網頁操作。

### 1.2 技術特點與效能保證
1. **零安裝、零部署成本**：純靜態網頁架構，直接使用瀏覽器開啟即可作業，無需安裝任何外掛或授權。
2. **文書筆電 60 FPS 流暢度**：3D 採用 Three.js WebGL 程序化幾何（Procedural Low-Poly）引擎，針對一般無獨立顯示卡之文書筆電與平板深度優化，確保全室 3D 旋轉與第一人稱漫遊維持 60 FPS 順暢體驗。
3. **高精確度 CAD 規範**：支援 ANSI31 45° 雙斜線剖面標準填充、門窗自動打斷牆體與 90° 門扇開啟弧線、85cm 門扇迴轉半徑動線防呆。
4. **全端格式輸出**：一鍵輸出高解析度 PNG、向量 SVG、工程 A4 PDF 報告書與標準 JSON 專案檔。

### 1.3 支援瀏覽器與快捷鍵相容性
- **推薦瀏覽器**：Google Chrome、Microsoft Edge、Apple Safari、Mozilla Firefox 最新版本。
- **螢幕解析度建議**：1366×768 以上（推薦 1920×1080 雙分割或大螢幕作業）。

## 參、模組一：既有外牆建置與底圖描繪實務指南

此模組用於建立房屋的既有外框邊界，是整個規劃案的基石。

### 步驟 1：上傳現況底圖
1. 在左側面板點擊 **「📁 上傳底圖」** 按鈕。
2. 選取現況手繪草圖、房仲格局圖或測量成果圖（支援 JPG / PNG / WEBP 格式）。
3. 底圖載入後，可透過 **「底圖透明度滑桿」**（預設 45%）調整明暗，便於後續描繪牆線。

### 步驟 2：兩點比例尺校正（重要：確保 1:1 實體尺寸）
1. 點擊左側 **「📏 比例尺校正」** 按鈕。
2. 滑鼠移至畫布上，在底圖上有標示尺寸的線段起點（如客廳面寬起點）點擊第一點（起點會顯示金色圓圈標記）。
3. 移至線段終點點擊第二點，系統將自動跳出 **「輸入該線段實際長度 (cm)」** 對話框。
4. 輸入實際尺寸（例如：`480`），點擊確定後，系統會自動換算全圖的公分比例尺（cm/px），後續所有拉線與坪數計算均達到公分級精準度。

### 步驟 3：繪製外牆與結構牆
1. 點擊左側 **「繪結構外牆 (E)」**。
2. 系統預設開啟 **「磁吸與端點自動吸附 (Snap)」** 與 **「90° 正交鎖定 (Ortho Lock)」**。
3. 在畫布上依序點擊各角落節點，即可依 24cm 標準厚度拉出封閉外牆。
4. **外牆屬性特性**：外牆會自動標記為 `locked: true`，系統外觀呈深海軍藍，受安全鎖保護，後續套用任何自動隔間演算法時，**絕對不會位移既有外牆**。
5. 牆體內部會自動填入符合國際建築製圖規範之 **ANSI31 45° 雙斜線剖面線**。

### 步驟 4：嵌入門扇與採光窗
1. **嵌入室內單開門 (D)**：點選後移至目標牆體，滑鼠游標自動吸附於牆線上，點擊即可完成嵌入。系統會自動在牆體打斷開口，並繪製標準 CAD 90° 門扇開啟虛線圓弧。
2. **嵌入採光窗 (N)**：點選後移至外牆，點擊即可嵌入四線窗框符號。
3. **翻轉門扇 (翻轉方向 / 鉸鏈側)**：點選已嵌入的門扇，點擊畫布上方快捷列的 **「🔄 翻轉門扇」** 按鈕，即可快速切換內開/外開或左開/右開。

## 肆、模組二：玄關連動與參數化自動隔間實務指南

本模組為系統核心亮點，業務同仁僅需設定 3 個關鍵錨點，系統便能自動推理公私動線並生成 2～3 組室內格局方案。

### 4.1 三大關鍵錨點定位
同仁可在右側面板或直接在 2D 畫布上設定三大錨點：
1. **入口玄關大門錨點**：
   - 位於外牆邊界上，以綠色門扇與「🚪 入口玄關大門」徽章醒目標示。
   - 可在右側選單選擇外牆方位（南向/北向/東向/西向），並滑動「偏移滑桿」；或直接在畫布上用滑鼠拖曳大門位置。
2. **固定水電管道間錨點**：
   - 以藍色水滴圖示「💧 水電管道間」標記於畫布上。
   - 代表現場無法輕易遷移的大樓共同排污管、糞管與給水幹管位置。
   - 同仁可用滑鼠自由拖曳至現況真實管道間位置。
3. **既有開窗採光面**：
   - 在右側點選北採光、南採光、東採光、西採光按鈕，外牆外側將即刻亮起金色採光指示帶。

### 4.2 拓撲動線自動隔間演算法
當同仁移動「入口玄關」或「水電管道間」時，系統依照建築空間拓撲邏輯即時重算：
- **玄關進門處**：配置緩衝落塵區與鞋櫃動線。
- **公領域**：玄關直通開闊客廳與餐廳。
- **私領域**：主臥室與次臥室優先排佈於**有採光面**之外牆側，確保每間房間皆具備自然通風與日照。
- **水電濕區**：衛浴與廚房自動吸附於**固定水電管道間**周邊，將水電泥作管線施工成本壓至最低。

### 4.3 內建 3 組經典自動隔間方案
右側面板提供 3 組一鍵套用方案：
1. **自動方案 1：標準公私分明雙臥（2房2廳1衛1廚）**
   - 適合：精緻家庭、穩定上班族合租、長期包租標準案。
   - 特色：玄關獨立落塵、客餐廳方正大器、雙臥皆開窗採光、衛浴乾濕分離。
2. **自動方案 2：外商主管大尺度一房一書房（1大房+1開放書房+雙廳）**
   - 適合：高階商務客、外商外派主管、新婚頂客族。
   - 特色：打通次臥為穿透式採光書房，主臥尺度奢華，可擺設加大雙人床與獨立更衣區。
3. **自動方案 3：高收益緊湊三房配置（3房1廳1衛）**
   - 適合：大學學區、商圈分租套雅房、投報率最大化規劃。
   - 特色：坪效利用率極致化，壓減走道無效浪費，創造 3 間具開窗條件的獨立房間，顯著拉高全戶月租金總收益。

### 4.4 免 CAD 指令之直覺拖拉微調
套用方案後，若同仁需要微調特定空間尺度：
1. **滑鼠拖拉隔間牆**：
   - 直接用滑鼠按住室內隔間牆中心點的金色圓形手把進行拖拉。
   - 相連的直角牆體會自動維持封閉相連，牆長尺寸與房間坪數同步即時連動跳動。
2. **點擊尺寸數字直接修改淨寬（cm）**：
   - 2D 畫布上各房間內部均有藍金色尺寸標籤（例如 `↔ 淨寬 380 cm`）。
   - 直接點擊該數字標籤，將彈出 **「輸入房間目標淨寬 (cm)」** 輸入框。
   - 輸入目標值（例如將 `380` 改為 `420`），系統將自動平移相應隔間牆，實現毫米級精準度。
3. **自動即時計算坪數**：
   - 系統依據封閉空間多邊形即時計算面積，並依台灣標準公式自動換算：
     $$\text{面積 (坪)} = \text{面積 (m}^2) \times 0.3025$$
   - 右側清單即時列出全室總面積、總坪數及各房間明細表。

### 5.2 智慧操作特性
1. **貼牆自動轉向（Auto-Align to Wall）**：
   - 當家具被拖曳靠近任何牆面（≤ 25cm）時，系統將自動旋轉角度使家具長邊貼齊牆面，免除手動旋轉微調之苦。
2. **開門迴轉半徑（85cm）動線防呆碰撞偵測**：
   - 門扇開啟扇形區域為必留通行廊道。
   - 若任何家具（如床尾、衣櫃角、茶几）侵入門扇 85cm 迴轉半徑內，該家具在 2D 畫布上將立即呈現**亮紅色粗框警示**，提醒同仁門扇會撞擊家具，有效預防裝潢完工後的客訴問題。
3. **旋轉與刪除快捷操作**：
   - 點選畫布上的家具，按鍵盤 `R` 或點擊頂部 **「旋轉 90° (R)」** 按鈕即可順時針旋轉。
   - 按鍵盤 `Delete` 或 `Backspace` 即可刪除選取物件。

## 陸、模組四：多版本比對、一鍵轉 3D 與業務成果出圖

### 6.1 多版本管理與評估比對
同仁可在頂部切換三個平行版本：
- **原始屋況**：現場勘查之老舊格局。
- **方案 A**：主力推薦格局（例如：雙臥高質感家庭房）。
- **方案 B**：備選高收益格局（例如：緊湊三房分租套房）。
- **複製方案**：點選 **「複製至...」**，可快速將方案 A 複製至方案 B 進行局部修改。
- **版本比對 Modal**：點擊 **「⚖️ 版本比對」**，即刻彈出橫向三卡對照表，同時呈現三個方案的總坪數、房間數、雙人床配置率與裝修成本收益綜合評估。

### 6.2 3D 即時轉換與沉浸式漫遊
點擊頂部 **「2D + 3D 同步視窗」** 或 **「3D 立體預覽」**：
1. **程序化自動幾何擠出**：
   - 系統依據設定之樓高（預設 300cm，可由上方輸入框自由調整）將 2D 牆面自動垂直擠出。
   - 門洞自動挖空至 210cm 標準門高，窗洞自動挖空並保留 90cm 窗台。
   - 2D CAD 線條圖塊自動對應替換為立體 Low-Poly 3D 家具（雙人床含床墊枕頭、沙發含座墊靠背、流理台含水槽水龍頭）。
2. **視角模式一：俯視娃娃屋視角（Dollhouse View）**
   - 預設模式，模擬拆除天花板的立體透視模型。
   - **智能剖切外牆（Cutaway Wall）**：勾選「自動剖切外牆」後，系統會自動偵測視角方位，將遮擋視線的外牆自動調降至 22% 高度，同仁無需手動隱藏牆壁即可一眼俯瞰全室格局。
   - 滑鼠左鍵拖曳旋轉、右鍵平移、滾輪縮放。
3. **視角模式二：室內第一人稱漫遊視角（First Person Walkthrough）**
   - 點擊 **「🚶 室內漫遊」**，鏡頭切換為租客視角（眼高 165cm）。
   - **操作方式**：
     - 使用鍵盤 `W / A / S / D` 或方向鍵前後左右走動。
     - 滑鼠在 3D 視窗內按住拖曳可旋轉視角環顧四周。
     - 手機/平板亦可透過右下角之觸控方向羅盤進行導航。
   - 向屋主簡報時，可直接讓屋主體驗站在客廳與主臥的開闊採光感。

### 6.3 成果匯出與業務提案應用
在右側面板「模組四：成果出圖」中，可自訂輸出規格：
1. **勾選項目**：尺寸標註線、空間名稱與坪數、全戶坪數統計表、指北針、港居不動產浮水印。
2. **三種格式一鍵出圖**：
   - **📷 匯出 PNG 平面圖**：高解析度（1920×1080+）圖檔，適合直接傳送至 Line 群組或刊登於租屋網站。
   - **📐 匯出 SVG 向量圖**：無限放大不失真向量格式，適合美工團隊進一步編排廣告海報。
   - **📄 匯出工程 PDF 報告書**：標準 A4 橫式工程圖框，包含工程標題、業主資料、指北針、坪數統計表與港居不動產官方聯絡資訊，可直接列印作為租賃代管合約附件或提案簡報。

### 6.4 專案持久化與多人協作
1. **儲存專案**：將整份專案（包含三方案、底圖、牆體、家具配置）儲存至瀏覽器 LocalStorage 本機資料庫。
2. **歷史專案**：點擊可檢視過去所有規劃專案，支援一鍵載入與刪除。
3. **匯出 JSON**：下載單一結構化 JSON 檔案（例：`高雄小港中安路_規劃案_20261023.json`），方便以 Email 或雲端存檔。
4. **匯入 JSON**：同仁接收他人的 JSON 檔後，點選匯入即可 100% 還原所有設計。
5. **🔗 分享連結**：系統將設計方案壓縮為 URL Hash（Base64 格式），一鍵複製網址傳給同仁或客戶，對方打開瀏覽器即可立即檢視，完全無需後端資料庫支援！

### 7.2 常見操作問題 FAQ

**Q1：為什麼上傳底圖後，拉線繪製的牆長與實際現場量測不符？**  
**A**：請先執行「兩點比例尺校正」。在底圖上找出已知長度的標註線（例如大門寬度 100cm 或主臥面寬 350cm），使用比例尺工具點擊兩端點並輸入實際公分數，系統即可自動完成全圖 1:1 校正。

**Q2：如何防止自動隔間方案把已經確定保留的承重牆移掉？**  
**A**：請使用「繪結構外牆 (E)」工具繪製承重牆，外牆預設具備鎖定保護（`locked: true`），任何自動演算邏輯均保證不會移動外牆。

**Q3：門扇開啟方向與現場相反，該如何調整？**  
**A**：在 2D 畫布上點選該門扇，點擊上方工具列的 **「🔄 翻轉門扇」** 按鈕，系統會依序切換外開/內開與左開/右開。

**Q4：家具周圍出現醒目的紅色警示框，是什麼原因？**  
**A**：這代表該家具侵入了門扇開啟的 **85cm 迴轉半徑扇形區**。請使用滑鼠將家具往遠離門扇的方向挪移，直到紅色警示消失，以確保完工後開門順暢不卡動線。

**Q5：切換到 3D 視角時，外牆太高擋住內部隔間該怎麼辦？**  
**A**：請確認已勾選畫布上方的 **「自動剖切外牆」**（預設開啟）。在娃娃屋俯視角下，靠近相機側的外牆會自動降至 22% 高度；您亦可直接點選 **「🚶 室內漫遊」** 進入室內視角無障礙檢視。

**Q6：在筆電上如何平移 2D 畫布？**  
**A**：按住滑鼠右鍵或在空白處按住左鍵拖曳，即可平移整個 2D CAD 畫布；使用滑鼠滾輪或觸控板雙指滑動即可縮放視圖。
