> **文件版本**：v1.0.0（2026 正式版）  
> **隸屬專案**：港居不動產開發有限公司（GANJU Real Estate，統編 `96797997`）官方網站與內部空間規劃工具集  
> **對應頁面**：`space-planner.html` ／ 樣式：`css/space-planner.css` ／ 核心引擎：`js/space-planner.js`

## 1. 專案目標與系統定位

本系統為專供港居不動產團隊同仁（包租代管開發、空間規劃師、業務顧問）使用的 **「Web 端互動式 2D 平面格局配置與 3D 即時轉換系統」**。
旨在解決包租代管案場評估、老屋微改造隔間規劃與房東提案時，傳統 AutoCAD / SketchUp 操作門檻高、硬體需求重的痛點：

1. **免 CAD 指令直覺操作**：滑鼠點擊拉線、拖曳隔間牆、點擊尺寸直接改淨寬（cm），即時換算平方公尺（$m^2$）與台灣慣用坪數（$1\text{ m}^2 = 0.3025\text{ 坪}$）。
2. **文書筆電 60 FPS 極致流暢**：2D 採用高解析 HTML5 Canvas / SVG 渲染標準 CAD 45° 剖面線（ANSI31 Hatch）與國家標準建築圖塊；3D 採用 Three.js (WebGL) 程序化低多邊形幾何（Procedural Low-Poly Geometry），零外部巨型模型載入延遲，在一般無獨立顯卡的內顯筆電上穩定維持 60 FPS。
3. **多方案比對與業務出圖**：單一 JSON Schema 完整封裝「原始屋況 / 方案 A / 方案 B」，支援一鍵輸出附帶坪數統計表、指北針與港居浮水印的 PNG / SVG / PDF 格局圖，以及產生唯讀預覽分享連結。

### 2.1 與 React / Next.js 企業內部系統整合映射
本系統採用高內聚狀態驅動架構（State-Driven Architecture），核心資料流與渲染器完全解耦：
- **純靜態部署模式（GitHub Pages / 本地直開）**：由 `space-planner.html` 載入 `js/space-planner.js`，零建置步驟即可運行。
- **React / Next.js 模組化封裝**：核心引擎掛載於 `window.GanjuSpacePlanner`，可直接於 Next.js App Router (`<SpacePlannerCanvas projectData={state} onChange={setState} />`) 中作為受控組件（Controlled Component）引入，並透過內建之 `StorageAdapter` 對接後端 PostgreSQL / MongoDB 資料庫 API（`POST /api/projects`、`GET /api/projects/:id`）。

## 4. 四大核心功能模組設計細節

### 模組一：既有外牆建置與底圖描繪（鎖定外框邊界）
1. **底圖上傳與兩點比例尺校正**：
   - 支援上傳 JPG / PNG / WEBP 既有平面圖或手繪測量圖。
   - 啟動「📏 比例尺校正」後，於底圖上點擊兩點繪製基準線 $\overline{P_1 P_2}$，輸入實際長度 $L_{\text{actual}}\text{ (cm)}$，系統即以 $\text{scaleCmPerPx} = \frac{L_{\text{actual}}}{\|\vec{P_2} - \vec{P_1}\|_{\text{px}}}$ 自動完成全圖 1:1 比例尺校正。
2. **互動式拉線繪牆**：
   - 支援格線吸附（預設 10cm）、既有牆體端點吸附（磁吸半徑 20cm）、正交鎖定（90° 水平/垂直鎖定）與即時尺寸標註。
3. **牆體分類與 ANSI31 剖面線**：
   - **既有外牆／結構牆（`type: "exterior"`, `locked: true`）**：預設牆厚 20/24cm，鎖定外框不可被自動隔間演算法移動。
   - **室內隔間牆（`type: "interior"`, `locked: false`）**：預設牆厚 10/12/15cm，支援自由拖拉與自動生成。
   - 牆體內部以 Canvas Clipping Path 繪製標準 CAD 45° 雙斜線剖面填充（ANSI31 Hatch），門窗開口處自動打斷牆線並繪製門扇開啟 90° 弧線或標準窗線。

### 模組二：玄關連動與參數化自動隔間（智慧空間配置）
1. **三大關鍵空間錨點**：
   - **🚪 入口玄關大門**：附著於外牆，可沿外牆周界自由拖曳。
   - **☀️ 既有開窗採光面**：可指定東、西、南、北任一或多個外牆面為採光側。
   - **🚰 固定水電管道間**：可於室內自由拖曳，決定衛浴與廚房流理台之最佳排水落點。
2. **拓撲驅動全局連動演算法**：
   - 當拖曳「入口玄關」或「水電管道間」時，演算法依據 **「玄關（入口）→ 客餐廳（公領域）→ 衛浴/廚房（貼近管道間）→ 臥室（貼近開窗採光面）」** 的空間拓撲優先序，即時演算 3 組隔間方案：
     - **方案 1：標準公私分明（2房2廳1衛1廚）**
     - **方案 2：大尺度開闊客餐廳（大主臥＋開放書房＋1衛1廚）**
     - **方案 3：高收益緊湊三房（3臥室＋客餐廳＋1衛1廚）**
3. **免 CAD 指令拖拉微調與坪數換算**：
   - 滑鼠直接拖曳室內隔間牆即可調整房間深寬，相連牆體自動延伸修剪。
   - 點擊畫布上的尺寸標籤可直接輸入目標淨寬（cm）。
   - 各空間即時計算平方公尺與坪數（$\text{坪數} = \text{m}^2 \times 0.3025$）。

### 模組三：標準 CAD 家具圖塊庫與自動避讓

2. **智慧貼牆與動線防呆**：
   - **Auto-Align to Wall**：拖曳家具靠近牆面 28cm 內時，自動將家具背面貼齊牆面內側並自動旋轉面向室內。
   - **門扇迴轉半徑（80~90cm）衝突檢測**：即時計算所有門扇開啟扇形區與家具邊界盒（OBB/AABB），若發生重疊則以紅色警示框、斜線陰影與狀態列訊息提醒。

3. **家具自訂長寬高與色彩風格調色盤**：
   - 選取家具後，屬性面板即刻展開寬度、深度、高度數值微調（20~280cm）。
   - 內建 6 款專用色彩風格預設（經典原木 `#C8B294`、沉穩胡桃木 `#5D4037`、港居海軍藍 `#1A365D`、典雅香檳金 `#C5A059`、現代石墨灰 `#475569`、極簡米白 `#F8FAFC`）與原生 Color Picker 自由選色，2D 畫布與 3D WebGL 家具模型即時連動著色。

### 模組四：多方案切換、一鍵轉 3D 與成品出圖
1. **2D / 3D 即時轉換（Three.js WebGL）**：
   - 支援「純 2D 平面」、「2D+3D 左右同步分割視窗」、「純 3D 立體預覽」三種檢視模式。
   - 依設定樓高（預設 300cm）將 2D 牆體擠出為立體牆面，自動挖空門洞（高 210cm）與窗洞（檯度 90cm、窗高 120cm 並鑲嵌半透明玻璃）。
2. **全室與獨立空間地面材質（3D 程序化貼圖）**：
   - 內建 5 款擬真地面鋪設材質：**溫潤淺橡木地板**、**沉穩深胡桃木地板**、**60×60 奢華石英磚**、**淺灰微水泥粉光**、**經典黑白石材**。
   - 支援頂部工具列全室一鍵切換，以及選取單一房間個別覆寫（如衛浴獨立石英磚）；以 Canvas Procedural Texture 即時生成木紋、拼縫與磚線，無外部圖檔依賴，內顯筆電 60 FPS 零延遲。
3. **雙 3D 視角模式**：
   - **俯視娃娃屋視角（Dollhouse View）**：隱藏天花板，支援「視角側外牆自動半降剖切」，方便一眼鳥瞰全室動線。
   - **室內第一人稱漫遊視角（First-Person View）**：視點高度 165cm，支援滑鼠環視與鍵盤 `WASD` / 方向鍵或畫面虛擬方向鈕於室內自由走動。
4. **業務成果匯出與分享**：
   - **標準工程圖匯出**：自訂勾選尺寸標註、空間名稱、坪數統計表、指北針、港居品牌浮水印，一鍵匯出 **PNG 高解析圖檔**、**SVG 向量圖** 與 **PDF A4 工程圖紙**。
   - **✨ 2400×1600 高質感租賃行銷宣傳圖（591 / FB / LINE 專用）**：專為物件刊登打造，自動採用設計師柔和粉彩色塊、家具立體陰影、空間坪數摘要表、隨附家具設備清單、採光方位與港居品牌經理人服務專線（0968-863-880）與法定證號，產出即為可直接發布之精緻宣傳海報。
   - **資料持久化**：支援 LocalStorage 本機資料庫存檔、匯出/匯入 `.json` 專案檔與產生 URL Hash 唯讀分享連結。
